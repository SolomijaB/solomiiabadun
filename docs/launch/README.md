# Launch-Freigaben

Die fachlichen Launch-Gates bleiben offen, bis alle Nachweise vollständig vorliegen. `npm run validate:launch` prüft weiterhin ausschließlich diese formale Launch-Reife. Eine Freigabe gilt nur mit einer eigenen Zeile `Status: FREIGEGEBEN` im jeweiligen Dokument.

Die vom Auftraggeber ausdrücklich angeordnete vorläufige öffentliche Bereitstellung ist separat in `vorabveroeffentlichung.md` dokumentiert. Sie ersetzt keine fachliche, rechtliche oder personenbezogene Freigabe und ändert keinen offenen Gate-Status.

Aktuell sind alle Freigaben bewusst offen.

- `gewerbedaten.md`: endgültige Unternehmens- und Gewerbedaten einschließlich Behörde und WKO-Zuordnung
- `rechtliche-pruefung.md`: fachliche Prüfung von Impressum und Datenschutzerklärung anhand des tatsächlichen Produktionsbetriebs
- `logo-freigabe.md`: Freigabe des finalen Logos durch Solomiia
- `foto-freigaben.md`: freigegebene Originalfotos und Entfernung aller KI-Entwurfsbilder
- `testimonial-freigaben.md`: echte freigegebene Stimmen oder bestätigte Entfernung der lokalen Beispiele
- `kontaktformular-versand.md`: aktivierter FormSubmit-Empfänger, geprüfter AJAX- und nativer Fallback-Versand sowie erfolgreiche echte Testzustellung

EVO Fitness wird im öffentlichen Quelltext nicht genannt. Eine spätere Ergänzung braucht vorab eine schriftliche Partnerfreigabe.
